# HW2 YARN с ресурсами по роли узла

## Требования
- ResourceManager
- NodeManager
- JobHistory Server
- Web UI доступны через localhost (SSH-туннели; согласно уточнению преподавателя)

## Установка
Точка запуска — `automation/cluster.yml`, параметры — `config/nastroiki.example.yml`.
Короткая инструкция: [INSTRUKCIYA](docs/INSTRUKCIYA.md).

## Проверка
QA / Network: [проверки YARN и доступ к Web UI через SSH](QA-NETWORK.md).
