# HW3: Apache Hive (Non-Embedded)

## Описание
Развернут Apache Hive 4.0.0-alpha-2 с внешним MySQL Metastore (не embedded), что позволяет подключаться нескольким клиентам одновременно. Реализована автоматизированная загрузка данных о литературе в партиционированную таблицу.

## Архитектура
- Hive Metastore: team-37-en (порт 9083)
- HiveServer2: team-37-en (порт 10000)
- Metastore DB: MySQL 8.0 на team-37-en (база `metastore`)

## Установка
Для развертывания Hive используется Ansible-плейбук:
```bash
cd ~/data-platform-homeworks
ansible-playbook -i shared/inventory.ini hw03-hive/ansible/install-hive.yml
```

## Загрузка данных
[`scripts/load_data.sh`](scripts/load_data.sh) создаёт тестовые CSV через `echo`, загружает их в HDFS и выполняет встроенный SQL через Beeline. Создаётся таблица `default.books` с партициями по году; повторный запуск заменяет учебные партиции. В конце скрипт выводит партиции, число строк по годам и все три книги. Исходные CSV сохраняются в HDFS для HW4.

## Проверка (Verification)

### 1. Ручная проверка через Beeline
Подключитесь к HiveServer2:
```bash
beeline -u "jdbc:hive2://team-37-en:10000/default" -n team
```

Выполните запрос для просмотра партиций:
```sql
SHOW PARTITIONS books;
```
**Ожидаемый результат:**
```text
+------------+
| partition  |
+------------+
| year=2022  |
| year=2023  |
+------------+
```

Выполните запрос для просмотра данных:
```sql
SELECT * FROM books;
```
**Ожидаемый результат:** таблица с тремя книгами («Война и мир», «Мастер и Маргарита», «1984»), где указан год издания.

Для выхода из Beeline введите:
```sql
!quit
```

### 2. Проверка одновременной работы нескольких клиентов
Для демонстрации того, что Hive не использует embedded-режим (как требуется в задании), запустите скрипт, имитирующий параллельную работу нескольких клиентов:
```bash
bash hw03-hive/clients/parallel_clients.sh
```

### 3. Сетевой доступ и QA-проверки
Для безопасного доступа к HiveServer2 извне и автоматизированной проверки данных используются скрипты QA:

bash hw03-hive/qa/open_hive_tunnel.sh
